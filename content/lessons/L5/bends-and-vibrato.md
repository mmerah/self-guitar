Bending a string raises the note like a voice; vibrato makes a held note sing. Goal: half-step bends on string 3, whole-step bends on string 2, all in tune, and an even vibrato, at 72 BPM.

## How to practise this

- 3 minutes: bend string 2 at fret 8 (G) up to A, then play A (string 1, fret 5) to compare. Repeat until they match.
- 5 minutes: the exercise from 52 BPM up to 72.
- Review: one pass of the legato exercise.

## How to bend

Use the **ring** finger, with the middle and index on the same string behind it. All three push together. The power comes from turning the wrist, like turning a door key, not from the fingers. The thumb can hook over the neck for leverage.

- **Half step:** up one fret in pitch. Start here, on string 3: fret 7 (D) bends to E♭, the bluesiest note there is.
- **Whole step (full):** up two frets. Do these on string 2, which is plain steel and bends easily: fret 8 (G) bends to A. On an acoustic, the wound string 3 rarely goes that far.
- **Release:** bend up, then let it come back down without picking.

Push strings 1–3 towards the ceiling; pull strings 4–6 towards the floor.

```atex
\tempo 60
:2 7.3{lf 4 b (0 2)} 8.3{lf 5} | :2 8.2{lf 4 b (0 4)} 5.1{lf 2}
```

## Vibrato

Vibrato is a small, steady bend and release, repeated: up a little, back to pitch, up a little. Rock the wrist as for a bend, just smaller. Keep the speed even, a few wobbles a beat, and save it for long notes.

::exercise{id="bends-and-vibrato-a"}

:::warning
Common mistakes:

- Bends that fall short (flat). Always check against the target note fretted.
- Bending with one finger only: it's weak and wobbly. Stack three.
- Vibrato that speeds up and slows down. Keep it even, like a steady pulse.

:::

**Mastery check:** three clean passes in a row of the bend exercise at 72 BPM, each bend in tune.
