In folk and country fingerpicking, the thumb works like a bass player: it alternates between two bass strings, one note per beat. It's the boom of boom-chick, played with the thumb. This lesson trains the thumb alone.

## How to practise this

- 2 minutes: alternate on C only, eyes closed, until the jump between strings 5 and 4 is automatic.
- 4 minutes: the exercise from 52 BPM up to 80.
- Try a gentle **palm mute**: rest the outer edge of your picking hand lightly on the strings right next to the bridge. The notes still sound, but short and punchy.
- Review: 2 minutes of the boom-chick exercise from Level 2.

## Which strings?

The thumb starts on the chord's **root**, then jumps to another bass string of the chord and back.

- **C**: string 5 (fret 3, the C) and string 4 (fret 2, an E).
- **G**: string 6 (fret 3, the G) and string 4 (open D).
- **Am**: string 5 (open A) and string 4 (fret 2, an E).

```atex
\tempo 70
:4 3.5{ch "C"} 2.4 3.5 2.4 | 3.6{ch "G"} 0.4 3.6 0.4
```

::chords{ids="C,G,Am"}

## Practise

Thumb only, C – G – Am – G, holding the full chord shapes. Count "1 2 3 4": root on 1 and 3, string 4 on 2 and 4.

::exercise{id="alternating-bass-c-g-am"}

::tool{name="metronome" bpm=60}

:::warning
Common mistakes:

- Losing the root when the chord changes (on G, the thumb must reach string 6).
- Uneven notes: the root louder than string 4. Make them equal.
- Moving the whole hand with the thumb. The fingers stay parked over strings 1–3.

:::

**Mastery check:** a clean pass of the exercise at 80 BPM.
