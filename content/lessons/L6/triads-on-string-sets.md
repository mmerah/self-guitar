A triad is three notes: root, 3rd and 5th. On three neighbouring strings it is small, clear and movable. Goal: play C, Am, F and G with the nearest triad each time.

## How to practise this

- 3 minutes: the C triads up strings 1–3, from 52 BPM.
- 5 minutes: the voice-led progression from 52 BPM up to 80.
- 1 minute: find the same C triads on strings 3–5 in the diagram.
- Review: the C arpeggio in the E shape, once.

## Three inversions

Stack the three notes in any order and you get three **inversions**: root position (root lowest), 1st inversion (3rd lowest) and 2nd inversion (5th lowest). On strings 1–3 they climb the neck in a loop.

## Lower string sets

The same notes move down a string set, but the shapes change. Strings 1–3 and 2–4 contain the G–B pair, tuned a major 3rd apart, so one note of each shape shifts up a fret. Strings 3–5 contain no B string: they are all 4ths apart, so their shapes differ again.

## Voice leading

Pick the inversion of the next chord that sits nearest the one you are holding. From C to Am only one note moves (G up to A); from Am to F only one (E up to F). Fewer moving notes sound smoother and are easier to play.

::exercise{id="voice-led-triads"}

::warning[Pick only the three strings. A stray open string under a triad changes the chord.]

**Mastery check:** three clean passes in a row of the voice-led progression at 80 BPM.
